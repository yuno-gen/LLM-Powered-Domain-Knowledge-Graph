# LLM-Powered Domain Knowledge Graph (VertexIQ)

Portfolio project: **VertexIQ** — an LLM-powered domain knowledge graph builder.

Documentation, setup, API examples, and architecture live in **[vertexiq/README.md](vertexiq/README.md)**.

```bash
cd vertexiq
python -m venv .venv && source .venv/bin/activate
pip install -r requirements.txt
cp .env.example .env   # add OPENAI_API_KEY
streamlit run app.py
```
